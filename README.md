# Финучёт — учебный практикум

## Запуск
1. Распакуйте ZIP целиком.
2. Откройте `index.html` в браузере.
3. Выберите полный вариант или тематическую тренировку.

Сайт работает без интернета, npm и внешних библиотек. Не открывайте HTML внутри архива. Все файлы должны оставаться в исходной структуре.

Если браузер ограничивает localStorage для локальных файлов, откройте терминал в папке сайта, выполните `python3 -m http.server 8000` и перейдите на `http://localhost:8000`. На Windows можно использовать `py -m http.server 8000`. Python нужен только для этого необязательного способа.

## Содержание
- Три полных варианта по 21 задаче, каждый на 40 баллов.
- 21 тематический блок, в каждом три версии соответствующей задачи из полных вариантов.
- 21 карточка формул, алгоритмов и типичных ошибок; поиск и отметки повторения.
- Числовой ввод, отдельный балл за каждый показатель, ввод наборов событий для форм отчетности.
- Тренировка с проверкой и фиксацией ответа; экзамен со скрытыми до сдачи решениями.
- Выбор времени: 30, 60, 90, 120 или 180 минут. Автосдача по времени.
- Сохранение текущей попытки, последних 50 результатов и отметок справочника.
- Работа над ошибками, разбор каждого ответа, адаптивное оформление.
- Исходный план PDF в `materials/plan.pdf`.

## Важные границы
PDF содержит план контрольной, а не отдельную программу экзамена. Экзаменационный режим — проверка по этим же темам. Официальная длительность не указана: таймер — учебная настройка.

Все задания, ключи и конспект авторские. Номера аналогов из PDF приведены для сопоставления; сами аналоги и лекции не были приложены. Три версии преимущественно меняют масштаб чисел; задача 1 повторяется, в задаче 20 меняется также число дней или запрошенный цикл. Это 21 тип и 63 экземпляра задач. Тематические блоки не добавляют новых уникальных заданий.

Суммы выражены в условных денежных единицах. Ставка НДС 20% в задаче 15 — учебное допущение условия, не справка о текущем законодательстве. Для методов амортизации и консолидации явно заданы применяемые соглашения. Используйте их при расчете.

## Правила проверки
Каждый показатель — 1 балл. В задаче 1 — по 1 баллу за полностью правильный набор событий для ББ, ОФР, ОДДС. В многочастной задаче учитывается каждый верный показатель независимо от других.

Ввод: `1 250,50`, `1250.50`, отрицательные числа со знаком минус. Не вводите валюту или единицы измерения. Промежуточные расчеты не округляйте, конечные — до двух знаков. Допуск проверки — 0,011 единицы. Для событий используйте русские буквы А–Е, порядок не важен.

При сдаче проверяются все введенные поля, в том числе не проверенные отдельно в тренировке. Пропуски дают 0. После проверки в тренировке ответ фиксируется; в экзамене его можно менять до сдачи. Работа над ошибками повторяет целиком задачу, где неверен хотя бы один показатель.

Таймер продолжает идти после ухода со страницы. Если срок истек при закрытой вкладке, результат фиксируется при возвращении. Хранится одна текущая попытка. Не используйте несколько вкладок одновременно. Данные не синхронизируются между устройствами; очистка данных браузера удалит прогресс.

## Файлы
- `index.html` — оболочка.
- `styles.css` — оформление, адаптированное из исходного сайта.
- `app.js` — интерфейс, проверка, таймер и сохранение.
- `data/content.js` — задания, ответы, объяснения и справочник.
- `materials/plan.pdf` — исходный план.
- `CONTENT_NOTES.md` — карта покрытия и статус материалов.

Добавление задания: объект в `variants` содержит уникальный `id`, номер `n`, название `title`, условие `text`, массив `fields` с `label`, `answer` и `kind` (`number` или `set`), решение `solution`, ссылку-номер `ref` и страницу `page`. При несовместимом изменении банка обновите `KEY` в app.js, чтобы старые попытки не конфликтовали с новыми заданиями.

## Раздел «2025»

Через навигацию «2025» доступен вариант из 19 задач с фотографий пользователя: 33 проверяемых показателя, тренировка и экзамен, сохранение прогресса и разбор. Данные находятся в `data/2025.js`. Номера задач и единицы ответа сохранены; ключи рассчитаны для практикума, официальные ответы и шкала оценивания не предоставлены. Полнота исходной контрольной не подтверждена.

Неоднозначности отмечены непосредственно в заданиях: классификация денежных потоков (6–7), порядок амортизации при пересмотре (9–10), состав затрат (12–13), противоречие ставок НДС 10% и 20% (18), учет НДС в расчетах (19). В задаче 18 принимаются НДС и валовая прибыль при обоих согласованных вариантах ставки. Тематические тренировки по-прежнему используют только три авторских пробника; их нумерация отличается от контрольной 2025.

## Классификация операций

Раздел «Классификация операций» содержит четыре задания (12 баллов) из документа `materials/impact-on-fs-a.docx`. Условия и ключи перенесены из документа, пояснения добавлены для практикума. Данные: `data/classification.js`. Поддерживаются буквы А–Ж и явный ответ «нет» для отчета без подходящих событий; пустое поле считается пропуском. Доступны тренировка, экзамен, сохранение и работа над ошибками.

В этом же разделе доступна «Классификация объектов учета» из `materials/classification-f.xlsx`: 32 объекта, 64 балла. Для каждого объекта выбираются категория и отчет (ББ или ОФР). Ключи и комментарии перенесены с листа Class. Поддерживаются тренировка, экзамен, сохранение и работа над ошибками.

## Баланс и прибыль

Отдельный раздел содержит задания из двух предоставленных документов: `materials/bs-pl-equations-a.docx` — 4 набора балансовых уравнений (16 баллов); `materials/bs-accounting-a.docx` — 4 набора операций с заполнением баланса (32 балла). Данные: `data/balance.js`. Ключи перенесены из документов и проверены расчетом; пояснения добавлены для практикума. Все ответы вводятся в тысячах рублей. Гипотетическая продажа в задачах на уравнения не учитывается в других вопросах набора. Особенности группировки процентов и авансов отмечены в условиях. Доступны тренировка, экзамен, сохранение прогресса, разбор и работа над ошибками.
